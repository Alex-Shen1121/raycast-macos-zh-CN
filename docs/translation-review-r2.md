# Raycast 2.9.0.0 R2 翻译审校报告

审校日期：2026-10-25。基线为 R1 提交 `a96af5bf2ffde16e52fe65ea197d5486b5d8e834`，适用于 macOS Apple Silicon 的 Raycast 2.9.0.0。

## 完整覆盖与处理结果

本次逐项覆盖 **18,248 个合并审校项、28,841 处出现位置**，包含原生界面、扩展商店、扩展词典、动态提示、拼接片段和表情名称。同一原文与译文合并成一项，其不同出现位置分别保留场景依据。

- 1007 项修改；159 项按场景分别处理或补齐关联显示逻辑。
- 17082 项保留，其中 4339 项表情名称与固定版本 Unicode CLDR 简体中文数据逐一核对一致。
- 49 个扩展使用本轮场景覆盖，共 137 个精确词条；另将 Brew 的固定版本与 Svgl 的列表置顶动态通知分开处理。
- 补扫了仅含标点的译文，修复订阅模型说明的前后拼接关系。
- 排除 1 项 Acorn Unicode 标识符字符集：其中虽含汉字范围，但它不是界面译文，保持原始数据。

六个词典分片逐项审校后，所有修改建议再由其他审校者独立复核；原生模板结合原版资源和调用上下文核对。程序检查用于验证覆盖、范围、占位符和语法，不替代语义审校。每项的决定、理由和原始出现位置见同目录的 `translation-review-r2.jsonl`。

## 实现与验证边界

修订从完整官方原版构建，保留原始 UTF-16 坐标及原文字面量断言；所有资源通过 JavaScript 语法检查。模板只改变显示结果，不改变比较条件、枚举、实际调用参数或用户名称。场景身份来自扩展清单名称和 API 环境，不使用共享的“当前扩展”变量。GitHub 的 Open Issues 进一步区分已识别的浏览器操作按钮与统计标签；无法证明身份的自定义包装组件仍保留原文。

安装、损坏保护、还原与本机界面验收的具体结果见 `验证报告.json`（仓库中为 `docs/verification-2.9.0.0-r2.json`）。源码审校已覆盖全部现有译文，实机验收仅覆盖报告列出的流程。

本包仍是非官方部分汉化。未逐一登录和测试全部扩展；原生菜单栏、未覆盖动态内容、远程页面及部分更新说明可能仍为英文。修改资源会使完整官方签名失效；没有修改原生可执行文件、重新签名或关闭系统安全保护，还原后检查官方签名。
