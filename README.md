# Raycast macOS 简体中文汉化 · 2.9.0.0

本分支将 [zwjtano/raycast-macos-zh-CN](https://github.com/zwjtano/raycast-macos-zh-CN) 的 2.8.2.0 汉化迁移到 **Raycast 2.9.0.0 · Apple Silicon / arm64**，提供安装包、恢复工具、可重建的翻译源码和测试。

这是非官方、部分汉化补丁，不包含 Raycast 原生主程序。仅支持指定版本和文件指纹，不能跨版本安装。

## 下载和安装

- [下载 2.9.0.0 汉化包](downloads/Raycast-2.9.0.0-arm64.zip)
- [SHA-256 校验文件](downloads/Raycast-2.9.0.0-arm64.zip.sha256)
- [验证报告](docs/verification-2.9.0.0.json)

1. 安装对应的官方 Raycast 2.9.0.0 arm64，放入“应用程序”，先正常打开一次。
2. 完全退出 Raycast，完整解压汉化包。
3. 双击“安装汉化.command”，回车使用 `/Applications/Raycast.app`，再回车确认安装。
4. 重新打开 Raycast。

安装无需 Python、Node.js 或开发工具，不自动提权。安装前检查完整版本、原生程序 SHA-256、全部原版资源和补丁资源，以及完整官方签名；拒绝符号链接和越界清单路径。

## 本次适配

- 在 2.9.0.0 原版资源上迁移翻译，保留新版代码、模块引用和机器字段。
- 覆盖 213 个资源文件、12,077 处替换（含英文检索词补全）；另保留上游的运行时显示翻译词典。
- 新增 218 条不同的 2.9 界面译文，包括最前方应用重启、声音设备管理、快捷键建议、听写改写、AI 设置和工作树状态。
- 补齐主搜索框、紧凑/展开窗口模式，以及快捷键和别名按钮的辅助功能标签。
- 将已汉化的静态内置命令原名保留为搜索关键词，兼容英文命令检索。
- 继承上游商店快照前十页 100 个插件和 Mole 的部分文案，详见[插件清单](installer/插件清单.md)。这不代表逐一验证所有插件的全部功能。

应用和插件名称、原生菜单栏、主搜索结果中的 `Command` 类型标签，以及未覆盖的动态内容可能仍为英文。继承 2.6、2.7、2.8 更新说明翻译，2.9 更新说明正文尚未完整汉化。部分开发调试界面和 Windows 专用文案不在本次新增翻译范围内。

## 恢复和更新

完全退出 Raycast，运行同一补丁包中的“恢复原版.command”。恢复会逐项检查备份和当前资源，随后验证完整官方签名。

备份位置：`~/Library/Application Support/Raycast-Chinese-Patch/2.9.0.0/`，按应用路径隔离。请保留汉化包和备份，不要移动已打补丁的应用。

升级前建议先恢复原版。本包不修改自动更新设置。应用已经更新或资源另有更改时，安装和恢复都会拒绝覆盖；不要用旧备份覆盖新版应用，也不要绕过指纹检查。

修改资源会使完整官方签名失效，部分机器可能被 Gatekeeper 拦截。本包不修改原生可执行文件、不重新签名、不移除隔离标记、不关闭系统安全保护，也不修改用户数据库、账户或插件设置。遇到启动拦截请恢复原版；恢复失败时重新安装相应官方原版。

## 从源码构建

需要 macOS 和 Node.js 22 或更高版本。Acorn 仅用于构建时的 JavaScript 语法检查；安装包不依赖系统 Node.js。

```sh
npm ci --ignore-scripts
npm test
node scripts/build.mjs /Applications/Raycast.app build/Raycast-2.9.0.0-arm64
node scripts/verify-install.mjs /Applications/Raycast.app build/Raycast-2.9.0.0-arm64
```

构建必须使用干净的官方 2.9.0.0。输出目录必须不存在，构建不会修改原版应用。安装测试自动创建独立的应用副本，不修改传入的原版应用。

- `translations/2.9.0.0.json`：原版资源指纹、准确替换位置、原文和译文。
- `translations/2.9-new-strings.json`：本次新增译文的对照表。
- `helpers/`：从上游包继承的显示翻译函数、词典和插件解析器。
- `installer/`：安装、恢复入口和第三方许可。
- `scripts/`：构建和真实应用副本的安装/还原验证。
- `tests/`：替换边界、路径约束、插件作用域及数据保留测试。

翻译位置使用 JavaScript 的 UTF-16 索引，构建先校验文件 SHA-256，再检查每处原文，最后解析生成的 JavaScript。后续版本必须重新对照资源，不能只改版本号或校验值。
